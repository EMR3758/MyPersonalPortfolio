# 💻 Kişisel Portfolyo Web Sitesi

ASP.NET Core MVC kullanılarak geliştirdiğim kişisel portfolyo web sitesi. Yazılım alanındaki çalışmalarımı, teknik yetkinliklerimi, eğitim bilgilerimi, deneyimlerimi ve projelerimi sergilemek amacıyla tasarladım.

Proje, Microsoft SQL Server veritabanı ile entegre çalışan dinamik bir yapıya sahiptir. Yönetim paneli üzerinden portfolyo içeriklerinin yönetilmesi hedeflenmiştir.

## 🏗️ Mimari

Proje, MVC (Model-View-Controller) mimarisi kullanılarak geliştirilmiştir.

- **Model:** Uygulamanın veri modellerini temsil eder.
- **View:** Kullanıcı arayüzünü oluşturur.
- **Controller:** Gelen istekleri yönetir ve uygulama akışını kontrol eder.
- **ViewComponent:** Tekrar kullanılabilir dinamik arayüz bileşenleri oluşturur.
- **Entity Framework Core:** Veritabanı işlemlerini gerçekleştirir.
- **DAL:** Veri erişim katmanını içerir.

## ⚙️ Kurulum

1. Projeyi klonlayın:

```bash
git clone https://github.com/EMR3758/MyPersonalPortfolio.git
```

2. Projeyi Visual Studio ile açın.

3. SQL Server bağlantı ayarlarını yapılandırın.

4. Gerekli Entity Framework Core migration işlemlerini uygulayın:

```powershell
Update-Database
```

5. Projeyi derleyin ve çalıştırın.
